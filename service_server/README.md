## 날씨 알리미 / SkyBuddy ##

### 서비스 설명 및 주요 기능

- 기상 데이터 시각적으로 표현하여 사용자의 편의성 제고 (해당 일자에 필요한 아이템(ex. 우산)이나 옷차림을 캐릭터화하여 보기 쉽게 표현)

- 기상 데이터나 기타 데이터들을 대시보드로 제공하여 정보 제공 (과거와 현재의 기후를 비교 분석하여 정보 제공 등 세부적인 기능 논의 중)

- 기후 예측을 통해 보다 정밀한 결과 제공


### 프로젝트의 특장점(기능 관점) ###

1. 사용자 친화적인 기상 정보 전달

   - 단순히 텍스트 기반의 날씨 정보가 아닌, 아이템(우산, 선글라스 등)이나 옷차림을 캐릭터화하여 시각적으로 표현함으로써 사용자들이 직관적으로 필요한 준비물을 인지할 수 있음.

   - 특히 연령대가 낮거나 날씨 데이터 해석이 익숙하지 않은 사용자들에게 높은 접근성과 편의성을 제공.

2. 맞춤형 대시보드 제공

   - 현재 날씨뿐 아니라 과거 데이터와의 비교를 통해 사용자가 기후 변화 추이를 한눈에 파악할 수 있도록 지원.

   - 시각적 그래프 및 통계 기반 분석으로 단순 정보 제공을 넘어 인사이트 제공 기능 강화.

3. 정밀한 기후 예측 기능

   - 단순 예보가 아닌 데이터 기반 분석을 통해 보다 정밀한 예측 결과를 제시.

   - 사용자 입장에서 단기적 준비뿐 아니라 중장기 생활 패턴에도 참고할 수 있는 가치 제공.


### 프로젝트의 특장점(기술 관점) ###

1. 데이터 시각화 기반의 차별성

   - 일반적인 기상 앱은 숫자/문자로 날씨를 제공하지만, 본 프로젝트는 캐릭터화된 시각적 인터페이스로 사용자 경험(UX)을 혁신.

   - 이는 단순 데이터 소비가 아닌 즐겁고 직관적인 정보 습득 과정을 유도한다는 점에서 독창적.

2. 분산 처리 기반 확장성

   - 초기에는 단일 서버·단순 통계 수준의 분석을 제공하더라도, 향후 Apache Spark를 활용한 대규모 기후 데이터 분산 처리 및 예측 모델링으로 확장 가능.

   - 대규모 기후 데이터셋을 효율적으로 처리할 수 있는 구조를 내재화함으로써 프로젝트의 확장성과 기술적 차별성 확보.

3. 예측 모델 정밀화 및 개인화 가능성

   - 단순 예보 데이터를 소비하는 것이 아니라, 기후 빅데이터와 머신러닝 기반 예측 모델을 활용하여 정확도를 높임.

   - 사용자의 지역, 생활 패턴, 과거 기상 데이터 활용 여부 등에 따라 맞춤형 날씨 가이드로 발전할 수 있어 기술적 독창성이 존재.

4. 데이터 통합 및 융합 활용

   - 기상 데이터뿐 아니라 교통, 생활, 환경 데이터와 결합 가능성이 있어 멀티모달 대시보드로 확장 가능.

   - 이는 단순 날씨 예보 서비스와 달리, 종합 생활 지원 플랫폼으로 진화할 수 있는 가능성을 내포.

### 팀 구성 ###
- Fe : 이순재, 임태원
- Be : 정시온, 최수빈
- Infra : 이효진
- De : 이웅희, 정시온

### 기술 스택 ###

- FE : React native, Typescript
- BE : SpringBoot
- DE : Kafka, Spark, Airflow
- Infra : Docker, S3, Ubuntu, AWS EC2, Jenkins, Nginx
- Monitoring : Prometheus, Grafana
- DB : MySQL
