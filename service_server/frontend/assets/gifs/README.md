# 🎭 GIF 캐릭터 에셋 가이드

## 🎬 필요한 파일

현재 단순 테스트를 위해 다음 파일이 필요합니다:

```
assets/gifs/
└── test_character.gif  # 테스트용 캐릭터 GIF
```

## 📋 GIF 요구사항

### 파일 형식
- **확장자**: `.gif`
- **해상도**: 512px 이하 권장 (성능 고려)
- **길이**: 2-5초 (자동 무한 반복)
- **프레임레이트**: 24fps 이하 권장
- **색상**: 256색 이하 (GIF 표준)

### 내용 요구사항
- **캐릭터 모션**: 자연스러운 루프 애니메이션
- **배경**: 투명 배경 권장
- **크기**: 세로형 비율 (2:3 또는 3:4)
- **용량**: 2MB 이하 권장

- ✅ **컴포넌트 구조**: AnimatedCharacter, AnimatedCharacterDisplay 완성
- ✅ **메인 화면 통합**: MainScreen에 연동 완료
- ✅ **단순한 구조**: Image 컴포넌트만 사용
- ⏳ **GIF 파일**: test_character.gif 파일 추가 필요

## 📱 테스트 방법

1. `test_character.gif` 파일을 `assets/gifs/` 폴더에 추가
2. 앱 새로고침 (Metro 재시작 불필요!)
3. 메인 화면에서 GIF 자동 재생 확인

## 🎨 GIF 제작 도구 추천

### **온라인 도구**
- [ezgif.com](https://ezgif.com) - 동영상 → GIF 변환
- [giphy.com/create](https://giphy.com/create) - GIF 제작
- [canva.com](https://canva.com) - 애니메이션 GIF

### **소프트웨어**
- **After Effects** - 고품질 애니메이션
- **Photoshop** - 프레임 애니메이션
- **GIMP** - 무료 GIF 편집

## 💡 MP4 → GIF 변환 팁

기존 MP4가 있다면:
1. **온라인 변환**: ezgif.com에서 MP4 업로드
2. **품질 설정**: 해상도 512px, 24fps 이하
3. **용량 최적화**: 색상 수 줄이기, 프레임 간소화
4. **루프 확인**: 자연스러운 반복 확인
